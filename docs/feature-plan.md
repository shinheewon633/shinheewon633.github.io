# 기능 명세 — 짧은 방명록

## 개요

내 포트폴리오 홈페이지에 "방명록" 기능을 추가한다.
방문자가 별명과 짧은 메시지를 남기면 서버를 거쳐 Supabase에 저장되고,
최근 글 목록이 화면에 다시 표시된다.

- 선택한 예시: 가이드 예시 3 (짧은 방명록)
- 배포 서비스: Netlify (+ Netlify Functions)
- 데이터 저장: Supabase (공통 필수)

## 다섯 문장 기획

- 내 홈페이지는 **나(신희원)를 소개하기** 위한 곳이다.
- 방문자는 **별명과 짧은 한마디 메시지를 남긴다.**
- 서버에는 **글 한 건(별명 + 메시지 + 저장 시각)을 저장한다.**
- 저장 후 화면에는 **최근 방명록 글 목록이 보인다.**
- **다른 기기에서도 같은 글이 보이고, 재배포 후에도 유지되면** 완성이다.

## 화면 구성

포트폴리오 하단에 "방명록" 섹션 추가:

- 별명 입력칸 (2~12자)
- 메시지 입력칸 (1~100자)
- [남기기] 버튼
- 최근 글 목록 (별명 · 저장 시각 · 메시지, 최신순)

동작:
- 페이지 로드 시: 서버에서 최근 글 목록을 불러와 표시
- [남기기] 클릭 시: "저장 중..." → 성공 시 입력칸 비우고 목록 갱신
- 실패 시: 실패 안내 표시 (성공으로 표시하지 않음)

## 저장할 데이터 (Supabase 테이블: guestbook_entries)

| 열 | 타입 | 설명 |
| --- | --- | --- |
| id | bigint (자동 증가) | 글 고유 번호 |
| nickname | text | 별명 (2~12자) |
| message | text | 메시지 (1~100자) |
| created_at | timestamptz (기본값 now()) | 저장 시각 |

## API (같은 사이트 내 Netlify Functions)

- `GET /api/guestbook` — 최근 글 목록 반환 (최신순, 최대 50건)
- `POST /api/guestbook` — body: `{ "nickname": "...", "message": "..." }` → 검증 후 저장

## 안전 규칙 (가이드 예시 3 기준)

- 별명 2~12자, 메시지 1~100자: **브라우저와 서버 양쪽에서** 검사
- 실명·연락처는 받지 않는다
- 방문자 입력은 HTML로 실행하지 않고 **글자 그대로 표시** (XSS 방지)
- 누구나 남의 글을 수정·삭제할 수 있는 API는 만들지 않는다 (읽기·쓰기만)

## 최소 완성 기준

- [ ] 빈 글/너무 긴 글은 거절
- [ ] 정상 글은 저장 후 최신순으로 표시
- [ ] 다른 기기에서도 같은 글이 보임
- [ ] `<b>안녕</b>` 입력 시 굵게 실행되지 않고 글자로 보임
- [ ] 저장 실패 시 성공 메시지를 띄우지 않음
- [ ] 재배포 후에도 글 유지

## 검사 방법

1. "안녕하세요"를 등록한 뒤 휴대폰으로 같은 글이 보이는지 확인
2. 빈 메시지는 저장되지 않는지 확인
3. `<b>안녕</b>` 입력 시 굵은 글씨가 아니라 문자 그대로 보이는지 확인
4. Supabase Table Editor에서 실제 행이 쌓였는지 확인

## 보안 메모

- Supabase secret 키는 Netlify 환경 변수에만 넣는다. 브라우저 코드/대화창/Git에 넣지 않는다.
- 공개 테이블에는 RLS를 켜고, 브라우저의 직접 접근 대신 서버 함수를 통해서만 저장한다.
